## 專案結構與個資隔離設計 (Data Isolation)

- **`data/`（完全受 `.gitignore` 隔離）**：存放所有真實學生名冊（`roster.csv`）與歷次成績登記檔案（`grade_*.csv`、`grade_*.xlsx`），確保絕對不會被意外 Commit 或 Push 到 GitHub。
- **`data.example/`**：提供脫敏的範例名冊（`roster.example.csv`），供專案開源或跨環境測試。
- **模組化程式碼與測試**：核心邏輯分拆為獨立子模組，並附帶完整單元測試。

## 人機互動與操作模式指南 (Human-Computer Interaction Guide)

系統針對助教與教師的實際登記場景，設計了極低認知負擔的三重人機互動模式：

### 1. 輸入互動模式 (Input Modalities)
- **多欄剪貼簿表格 (Multi-Column Paste)**：
  - 直接複製試卷或 Excel 的 `A+ \t A \t A-` 欄位文字並貼上終端，換行輸入 `END` 即可一鍵送出。
- **快捷學制與姓氏簡稱標記 (Program & Surname Shortcut Matching)**：
  - 遇到 4 組重複後兩碼時，可直接在輸入端附加學制標記，例如 `1博 A+`、`1碩 A`、`4碩 A+`、`7博 A+`。
  - 支援單字姓氏輸入（如 `朱` 或 `郭`）：若全班僅 1 位同姓同學則直接精確鎖定；若有多位同姓同學，系統將優先以姓氏前綴檢索，避免誤配名中含該字者。
- **單行鍵值對或自然文字 (Inline Key-Value)**：
  - 支援 `70 A, 61 A+, 29 A++` 或包含姓名/學號的自然行格式。
- **文字檔案載入 (File Import)**：
  - 終端主選單提供輸入檔案路徑選項，可直接讀取 `.txt` 批次資料。

### 2. 智慧防呆與衝突仲裁互動 (Smart Arbitration & Conflict Resolution)
- **同等級自動配對（免打擾模式）**：
  - 當重複號碼組的提交次數剛好吻合候選人數，且**所有等第皆相同**（如本次兩位 1 號同學皆為 A），系統會判定為無衝突並自動登記，不中斷操作流程。
- **排除法自動定錨 (Deductive Auto-Resolution)**：
  - 當多位候選人的同號組別中，若有候選人已在同輪輸入中透過精確姓名、完整學號或學制標記（如 `1博`）鎖定成績，同組剩餘的純數字標記將透過排除法自動分派給未定錨的候選人，無需助教再手動確認或碰撞互動。
  - 同姓氏簡稱排除關聯：若輸入單字姓氏（如「朱」）且名冊中其他同姓同學的學號已出現在輸入中，系統透過多輪級聯排除法自動將該姓氏標記分派給未出現之同姓同學。
- **單人超額防呆警報與智慧筆誤猜測 (Typo Guess Alert)**：
  - 若同一位同學重複出現在不同等第（例如既出現在 A+ 又出現在 A），或該後兩碼在全班僅有一人卻被登記兩次，系統會觸發醒目警報提示，列出所有衝突等第，供助教手動修正或略過，絕不靜默覆蓋。
  - 當全班缺繳人數極少（$\le 2$ 人）時，系統將自動比對未登記名冊，於警報中主動提示「疑似誤填同學名單」，並給出快速修正指令建議。
- **跨等級碰撞確認流程**：
  - 終端選單模式：列出候選組合（例如 `[1] 曾** A+ / 楊** A`, `[2] 曾** A / 楊** A+`），輸入數字即可決定。
  - 自然對話模式：支援簡短指令消解，如 `a 2 曾`、`a 4 潘`、`a 7 陳`，系統自動將對應同學歸入 A，同組另一人歸入 A+。

### 3. 檔案匯出互動 (Export Interaction)
- 登記流程結束時，系統提示自訂檔名（預設 Enter 自動以當日 `grade_YYYYMMDD` 命名）。
- 自動產出兩份檔案：標準 CSV 檔與專業美化版 Excel 檔（包含深藍表頭、最適欄寬、首行凍結與斑馬紋交替色）。

## 執行方式與自動化指令 (CLI Guide)

系統同時支援「真人互動終端」與「AI / 自動化批次指令」，無需編寫任何輔助腳本即可完成操作：

### 1. 真人終端互動模式
直接啟動互動選單（支援貼上、選單消解衝突、自訂檔名）：
```powershell
python run.py
```

### 2. 審計模式（僅分析與回報衝突，不寫檔）
傳入文字檔案或直接傳入內容進行防呆檢查：
```powershell
# 輸出人類易讀文字報告
python run.py -i raw_grades.txt --audit

# 或輸出 JSON 結構（適合程式或代理人串接）
python run.py -i raw_grades.txt --audit --json
```

### 3. 一鍵批次消解與產檔模式
支援命令列直接消解衝突與補登，一鍵產出 CSV 與美化 Excel：
```powershell
python run.py -i raw_grades.txt --resolve "50=A+, 01碩=A, 01博=A+, 04博=A, 04碩=A+, 07碩=A, 07博=A+, 賴**=A, 陳**=A" -o grade_20261103 -y
```
> 註：`--resolve` 支援學號（`115423001`）、學制後綴（`1碩`、`1博`）、末碼（`50`）、姓名模糊容錯（容許 1 字錯別字，如 `陳祈睿` 自動匹配 `陳祈叡`），以及**筆誤重指派替換語法**（例如 `14->72` 自動將 14 的其中一筆重指派給 72，或 `14->72=A` 指定指派等第）。

### 4. 無表頭剪貼簿多欄對齊 (`--headers`)
若複製試卷時未選取首行表頭（首行即為數字學號），可透過 `--headers` 注入指定各欄等第：
```powershell
# 複製內容為純數字多欄表格時，自動將第 1, 2, 3 欄對齊 A, A+, A++
python run.py -i raw_grades.txt --headers "A,A+,A++" -o grade_20261124 -y
```

### 5. 全學期歷次成績一鍵彙整總表 (`--consolidate`)
一鍵自動掃描並彙整 `data/` 下所有歷次作業登記紀錄（`grade_YYYYMMDD.csv`），產出全學期總表：
```powershell
# 自動產出 semester_grades_summary.csv 與 semester_grades_summary.xlsx
python run.py --consolidate

# 自訂檔名與 JSON 報告輸出
python run.py --consolidate -o term_final_summary --json
```
- **產出內容**：
  - 歷次作業成績欄位（依登記日期時間序列自動遞增排序）。
  - 全班統計指標：應繳次數、實繳次數、缺繳次數、繳交率（%）。
  - 等第次數分布：`A++`、`A+`、`A`、`A-` 次數。
  - 平均等第積分（GPA 4.3 制）。
- **專業 Excel 樣式**：
  - 凍結窗格（水平滾動時固定學號、姓名、學制）。
  - 缺繳標籤醒目標紅底色（`FCE4D6`）。
  - 深藍表頭與斑馬紋交替底色。

### 6. 執行單元自動化測試
可在本目錄直接執行單元測試套件：
```powershell
python -m unittest discover -s tests
```
