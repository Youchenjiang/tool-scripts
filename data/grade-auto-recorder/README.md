## 專案結構與個資隔離設計 (Data Isolation)

本專案採「代碼與數據完全分離」與「模組化架構」設計：
- **`data/`（完全受 `.gitignore` 隔離）**：存放所有真實學生名冊（`roster.csv`）與歷次成績登記檔案（`grade_*.csv`、`grade_*.xlsx`），確保絕對不會被意外 Commit 或 Push 到 GitHub。
- **`data.example/`**：提供脫敏的範例名冊（`roster.example.csv`），供專案開源或跨環境測試。
- **模組化程式碼與測試**：核心邏輯分拆為獨立子模組，並附帶完整單元測試。

```text
grade-auto-recorder/
├── data/                    # [已 Git 忽略] 真實名冊與各次成績 (.csv, .xlsx)
├── data.example/            # 脫敏名冊範例 (供測試)
├── grade_recorder/          # 模組化核心套件
│   ├── __init__.py          # 套件入口與匯出宣告
│   ├── models.py            # Student & Roster 資料模型

│   ├── exporter.py          # CSV 與美化版 Excel (openpyxl) 匯出器
│   └── cli.py               # 命令列互動選單與流程控制
├── tests/                   # 單元測試套件
```

## 人機互動與操作模式指南 (Human-Computer Interaction Guide)

系統針對助教與教師的實際登記場景，設計了極低認知負擔的三重人機互動模式：

### 1. 輸入互動模式 (Input Modalities)
- **多欄剪貼簿表格 (Multi-Column Paste)**：
  - 直接複製試卷或 Excel 的 `A+ \t A \t A-` 欄位文字並貼上終端，換行輸入 `END` 即可一鍵送出。
- **快捷學制標記 (Program Shortcut Matching)**：
  - 遇到 4 組重複後兩碼時，可直接在輸入端附加學制標記，例如 `1博 A+`、`1碩 A`、`4碩 A+`、`7博 A+`。系統將跳過互動確認直接精準定錨。
- **單行鍵值對或自然文字 (Inline Key-Value)**：
  - 支援 `70 A, 61 A+, 29 A++` 或包含姓名/學號的自然行格式。
- **文字檔案載入 (File Import)**：
  - 終端主選單提供輸入檔案路徑選項，可直接讀取 `.txt` 批次資料。

### 2. 智慧防呆與衝突仲裁互動 (Smart Arbitration & Conflict Resolution)
- **同等級自動配對（免打擾模式）**：
  - 當重複號碼組的提交次數剛好吻合候選人數，且**所有等第皆相同**（如本次兩位 1 號同學皆為 A），系統會判定為無衝突並自動登記，不中斷操作流程。
- **單人超額防呆警報（防止靜默覆蓋）**：
  - 若同一位同學重複出現在不同等第（例如既出現在 A+ 又出現在 A），或該後兩碼在全班僅有一人卻被登記兩次，系統會觸發醒目警報提示，列出所有衝突等第，供助教手動修正或略過，絕不靜默覆蓋。
- **跨等級碰撞確認流程**：
  - 終端選單模式：列出候選組合（例如 `[1] 曾** A+ / 楊** A`, `[2] 曾** A / 楊** A+`），輸入數字即可決定。
  - 自然對話模式：支援簡短指令消解，如 `a 2 曾`、`a 4 潘`、`a 7 陳`，系統自動將對應同學歸入 A，同組另一人歸入 A+。

### 3. 檔案匯出互動 (Export Interaction)
- 登記流程結束時，系統提示自訂檔名（預設 Enter 自動以當日 `grade_YYYYMMDD` 命名）。
- 自動產出兩份檔案：標準 CSV 檔與專業美化版 Excel 檔（包含深藍表頭、最適欄寬、首行凍結與斑馬紋交替色）。

## 執行方式與自動化測試

### 1. 執行成績登記
建議使用標準啟動入口：
```powershell
python run.py
```
（亦支援舊有習慣 `python grade_recorder.py`，內部將自動轉發至模組入口）

### 2. 執行單元自動化測試
可在本目錄直接執行單元測試套件：
```powershell
python -m unittest discover -s tests
```
